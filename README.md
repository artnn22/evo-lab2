# Лабораторная работа № 2

Генетический алгоритм для назначения аудиторий занятиям. Вариант **9**.

30 занятий, 6 аудиторий, фиксированное время. Требуется соблюдать вместимость,
исключить одновременное использование аудитории и уменьшить число пустых мест.
Входные данные синтетические, seed генерации **900**.

## Запуск

Все команды выполняются из корня проекта, где находятся `src/` и `requirements.txt`.
Рекомендуется Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m tests.test_problem
python3 -m src.experiment
```

Эксперимент выполняет 80 запусков: по 20 для трёх конфигураций ГА и случайного
допустимого поиска. Один запуск использует 11 660 оценок. Seed: 1000–1019.
Время зависит от компьютера; прогресс выводится после каждого запуска.

Данные уже включены в работу. Восстановить их из фиксированного seed:

```bash
python3 -m src.problem
```

После повторного эксперимента обновить оба формата отчёта:

```bash
python3 -m src.report
```

Построение отчёта читает CSV, расписание и исходные данные из этой папки.
Численные таблицы обновляются автоматически. Текстовые выводы относятся к
приложенной постановке и конфигурациям; при изменении данных или параметров
их нужно пересмотреть и проверить PDF визуально.

## Структура

- `src/` — модель задачи, паросочетание, ГА, случайный поиск, эксперименты и отчёт.
- `data/instance.json` — все входные данные; в генотипе аудитории индексируются с 0,
  в расписании их номера начинаются с 1.
- `configs/` — три конфигурации. Число запусков `RUNS = 20` задано в `src/experiment.py`.
- `tests/test_problem.py` — проверки, включая сравнение ремонта с полным перебором.
- `results/runs_*.csv` — итог каждого запуска, генотип, допустимость, оценки и время.
- `results/traj_*.csv` — лучшее допустимое значение и накопленная доля допустимых
  оценок по поколениям; у случайного поиска поколения означают равные блоки оценок.
- `results/summary.csv` — сводные результаты.
- `results/best.json`, `results/best_schedule.csv` — лучшее решение и его расшифровка.
- `results/*.png` — схема алгоритма и графики.
- [Отчёт Markdown](report.md), [отчёт PDF](report.pdf).

Операторы реализованы самостоятельно. NumPy нужен для случайных чисел,
Matplotlib — для графиков, ReportLab — только для PDF. Готовые оптимизаторы
не используются. Сетевой доступ при выполнении работы не нужен.

## Как понимать сравнение

Первый и второй ГА отличаются обработкой ограничений; второй и третий — мутацией.
Случайный поиск строит допустимые назначения через случайный порядок рёбер и
занятий в паросочетании. Он не равномерен по множеству всех допустимых решений.
Бюджет считает полные оценки кандидатов после обработки ограничений. Ремонт
и построение паросочетания не входят в число оценок, но входят во время запуска.
Равное число оценок поэтому не означает равное время.

Для этих данных все три ГА достигают 535 пустых мест; случайный поиск даёт
570–625. В отчёте приведена нижняя
граница, которая подтверждает оптимальность именно этого значения. Это простой
экземпляр задачи назначения; превосходство ГА над точными методами не утверждается.
